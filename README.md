# Amazing Project — 2D Room Layout & Interior Design Simulator

> A browser-based tool for designing room layouts. Draw a room, drag furniture into it, and size each piece in feet to see what actually fits before you buy or move anything.

**Project type:** Personal

## 💡 Why This Project?

<!-- TODO: In your own words: why you wanted this, and what problem it solves for you. -->

Furniture shopping and rearranging rooms involve a lot of guessing. Will that 7-foot couch fit along the wall? Is there still room to walk past the bed? This project lets you plan a room to scale in 2D before you move anything.

---

## ✨ Features

### Planned
- [ ] Create a room with a custom width and length (in feet)
- [ ] Save multiple room layouts
- [ ] Furniture palette with categories (couch, bed, table, chair, rug, dresser, etc.)
- [ ] Furniture dropdowns to set **width and length in feet** (e.g., Couch → 7 ft × 3 ft)
- [ ] Drag-and-drop furniture into the room
- [ ] Move and rotate furniture inside the room
- [ ] Everything drawn to scale with a grid (1 square = 1 ft)
- [ ] Delete / duplicate furniture
- [ ] Save and load layouts (local storage)

### Completed
- [x] Project setup: folder structure, README, time log

> Height is intentionally ignored. This is a top-down 2D planner.
